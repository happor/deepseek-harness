# Agent Loop

The turn/step engine and the model I/O vocabulary: what an agent is asked and with which tools and context, how one model call becomes a durable fact, and when the loop compacts what it remembers or stops. Terms shared with other contexts are defined once elsewhere — the [turn](../../glossary.md#turn) and [step](../../glossary.md#step) an agent drains, and the [exchange](../../glossary.md#exchange) they compose, belong to the root [glossary](../../glossary.md#loop-hierarchy); the [scope](../../glossary.md#agent-scope) an agent registers into belongs to the same file; and the [surface](../session-data/GLOSSARY.md) that carries model history belongs to [Session Data](../session-data/GLOSSARY.md).

## Language

### The turn engine

**Agent loop**: The harness's default driver, and the one implementation of the public Agent contract that plugins program against — which is why a composition can replace the loop without changing a consumer. It is the component that actually runs turns and steps: claiming input, assembling what the model is asked, dispatching tool calls, and appending every accepted fact before the next step derives from it. _Lives in_: `packages/core/agent-loop` · [core.md](../../subsystems/core.md) · group [README](../../../packages/core/README.md). _Avoid_: engine, scheduler, runner.

**Inbox**: The work an agent has been given but not yet consumed, kept as two ordered lists: prompts that each become their own turn, and input that joins the next step boundary. It is durable rather than in-memory, so pending work survives a reload and a reader with no live agent still sees what waits. _Lives in_: `packages/core/agent` (the contract) and `packages/core/agent-loop` (its durable form) · [core.md](../../subsystems/core.md). _Avoid_: queue, buffer, mailbox.

**Steering**: Input addressed to the nearest step boundary rather than to a new turn: a running loop takes it at its next step, while an idle loop opens a turn to consume it. A step refused before it starts leaves pending steering in place until something else wakes the loop. _Lives in_: `packages/core/agent` · [core.md](../../subsystems/core.md). _Avoid_: mid-turn message, interruption, follow-up.

**Injected context**: Model-visible context queued for a later step without waking the loop: a running loop claims it at the nearest later step boundary, and an idle loop leaves it pending. It may miss a request whose proposed batch was already claimed, and cancellation may discard it. _Lives in_: `packages/core/agent` · [core.md](../../subsystems/core.md). _Avoid_: system message, hidden prompt (steering wakes the loop; injection deliberately does not).

**Pre-step**: The single interception point between the input a proposed step would take and the request it would derive; its decision either refuses the step — leaving a turn that spends no step — or enters it with the authoritative message batch. Everything that may rewrite, add to, or veto a step's input works here, and no later attempt repeats it, including retries. _Lives in_: `packages/core/agent` · [core.md](../../subsystems/core.md) · [agent-lifecycle.md](../../agent-lifecycle.md). _Avoid_: middleware, hook, beforeRequest.

**Attempt**: One model call. A retried call is a fresh attempt inside the same open step, and an attempt that settled without leaving the model's message is kept as a log-only record, so failures, cancellations, and stream errors stay replayable without entering history. _Lives in_: `packages/llm/llm` · [llm-streaming.md](../../subsystems/llm-streaming.md) · [agent-lifecycle.md](../../agent-lifecycle.md). _Avoid_: try, request (the request is what is sent; the attempt is what is settled).

### The model request

**Model selection**: The durable choice of provider, model, and optional reasoning effort that a session's steps run on; a recorded choice outranks the last request, which outranks the agent's own options. An effort the adapter defaulted is deliberately not pinned as a choice, so a later request resolves the default again. _Lives in_: `packages/core/agent` and `packages/core/agent-default-model` · [core.md](../../subsystems/core.md). _Avoid_: route, model config, settings.

**Provider route**: One registered provider key through which models are reachable, and which selects the adapter instance that serves a request. The model catalog a route advertises is advisory only: a route may serve a model it never lists. _Lives in_: `packages/llm/llm` · [llm-streaming.md](../../subsystems/llm-streaming.md). _Avoid_: endpoint, backend, base URL.

**Prepared call**: One model call whose configuration and adapter registration were resolved together, and which is therefore carried through prompt admission, request logging, and dispatch under a single registration. Its declared capabilities govern how the rendered prompt is admitted, and a retry re-prepares the same rendered assembly instead of assembling again. _Lives in_: `packages/llm/llm` · [llm-streaming.md](../../subsystems/llm-streaming.md). _Avoid_: bound request, dispatch handle.

**Prompt admission**: The loop's synchronous decision about the rendered prompt in message history: taken from the prepared call's declared capabilities, it appends, replaces, or clears that prompt. A route that reads an in-history prompt may receive a changed prompt appended after cached history rather than have the first message rewritten, and an empty rendering clears whatever earlier requests retained. _Lives in_: `packages/core/agent-loop` · [agent-loop README](../../../packages/core/agent-loop/README.md) · [architecture.md](../../architecture.md#turn-flow). _Avoid_: prompt injection (that is behavior, not history handling), prompt rewrite.

**Finish reason**: Why one model response ended. A finish carrying tool calls obliges another step in the same turn, a plain stop or a token cap leaves the model's content as the answer while dropping tool calls from a truncated response, and an abort or error settles the attempt as a failure with no message committed. _Lives in_: `packages/llm/llm` · [llm-streaming.md](../../subsystems/llm-streaming.md). _Avoid_: stop reason, stop sequence (a generation control, not the ending).

**Prompt section**: One named, ordered contribution to the system prompt, either fixed text or resolved from current facts at each assembly; contributions come from the deployment or from a single agent's scope, where a same-named one shadows the global. A section may also claim the whole prompt, which turns assembly into a resolution pass that ends by restoring that section alone. _Lives in_: `packages/core/system-prompt` · [system-prompt.md](../../subsystems/system-prompt.md). _Avoid_: prompt fragment, prompt part, instruction file.

**Runtime context**: The cache-safe counterpart of a prompt section: current, per-step facts that the loop logs as a durable user-role snapshot after the retained history, writing only when they changed or when a compaction removed them. An optional contribution may be suppressed, while a required one survives suppression because the loop depends on it. _Lives in_: `packages/core/system-prompt` and the `packages/context` contributors · [system-prompt.md](../../subsystems/system-prompt.md). _Avoid_: dynamic context, dynamic prompt, system message.

### Tools and guards

**Step tool set**: The tool registrations admitted for one proposed step, deciding that step's model-visible declarations, the tools its calls may reach, and any sub-calls a program makes through them. Admission happens once per step and is released when the step's calls settle, so a same-name replacement or a new restriction stops only calls that have not yet started. _Lives in_: `packages/core/tools` · [tools.md](../../subsystems/tools.md). _Avoid_: tool list, allowlist (a [restriction](../../glossary.md#agent-scope) filters what a scope inherits; this is one step's admission).

**Tool continuation**: The further step a turn owes because its assistant message requested tool calls; before it, the loop claims any waiting next-step input and derives again from the results it has just logged. It is why a turn contains more than one step, and why a turn with outstanding calls is never terminal. _Lives in_: `packages/core/agent-loop` · [core.md](../../subsystems/core.md) · [tool-execution-pipeline.md](../../tool-execution-pipeline.md). _Avoid_: follow-up turn, retry.

**Loop-hygiene guard**: A policy that watches the running loop for one unproductive pattern and intervenes cheaply: the shipped pair spot a model repeating an identical tool call and a tool call outliving the limit it declared, and answer with a reminder or a clear error instead of a stall. It is not the tool pipeline's own monotonic guards, which may only deny a call or abstain from deciding. _Lives in_: `packages/guard` · group [README](../../../packages/guard/README.md) · [tools.md](../../subsystems/tools.md). _Avoid_: hook, middleware, interceptor.

### Compaction

**Context pressure**: How full a model route's context window is: the prompt size the provider last reported, plus an estimated delta for everything the history has gained or lost since. That makes it a display figure — compaction reports no usage of its own — while compaction policy measures the request itself through the same service, with a confirmed context overflow as its harder second trigger. _Lives in_: `packages/llm/token-meter` · [token-meter.md](../../subsystems/token-meter.md) · [compaction.md](../../subsystems/compaction.md). _Avoid_: token count, usage (the provider's per-call accounting is a different fact).

**Compaction**: Condensing a chosen span of older model-visible history into one summary, then replacing that span so later requests see the summary instead of the original messages; the original events stay in the log and only their visibility changes. It runs automatically on a trigger or on demand, and it is one optional capability rather than part of the loop's spine. _Lives in_: `packages/compaction` · [compaction.md](../../subsystems/compaction.md) · group [README](../../../packages/compaction/README.md). _Avoid_: condensation, context trimming, deletion.

**Summary checkpoint**: The single user-role message a compaction adds in place of the span it summarized, carrying the compaction's own transaction identity so a client can recognize and correlate the replacement without knowing which backend produced it. Everything else the compaction records is log-only and never reaches the model. _Lives in_: `packages/compaction/compaction` · [compaction.md](../../subsystems/compaction.md). _Avoid_: compaction message, summary block.

### Composition

**Agent preset**: A declaratively declared agent composition — the child plugins and metadata that give one agent its tools, prompts, and skills — bound to a session's agent before its first turn and retained as an exact revision. A child agent joins the revision its parent retained, so a conversation never silently moves to a newer preset. _Lives in_: `packages/preset` · [core.md](../../subsystems/core.md) · group [README](../../../packages/preset/README.md). _Avoid_: profile (a deployment profile is a bundle, not an agent), template, config.
